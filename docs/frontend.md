# Руководство по веб-интерфейсу

URL: `http://localhost:8000/web/`

Веб-интерфейс — полноценный фронтенд на Jinja2 + Bootstrap 5. Все действия выполняются через обычные HTML-формы без JavaScript (кроме Bootstrap-модалок). После каждого действия страница обновляется (паттерн POST-Redirect-GET).

---

## Регистрация и вход

### Регистрация
**URL:** `http://localhost:8000/web/auth/register`

1. Заполни поля **Имя** и **Фамилия** (необязательно)
2. Введи **Email** и **Пароль** (минимум 8 символов)
3. Нажми **Зарегистрироваться**
4. При успехе — автоматический вход и редирект на дашборд

Если email уже занят — появится красный алерт под заголовком.

---

### Вход
**URL:** `http://localhost:8000/web/auth/login`

1. Введи **Email** и **Пароль**
2. Нажми **Войти**
3. При успехе — редирект на дашборд, в навбаре отображается имя пользователя

---

### Выход
Кнопка **Выход** в правом углу навбара (видна только авторизованным).  
После выхода — редирект на страницу входа, сессия инвалидируется.

---

## Дашборд — мои команды

**URL:** `http://localhost:8000/web/dashboard`

Главная страница после входа. Отображает все команды, в которых состоит пользователь.

```
┌──────────────────────────────────────────┐
│  Мои команды          [Вступить] [Создать]│
├──────────────┬───────────────────────────┤
│ Backend Team │ Frontend Team             │
│ Описание...  │ Описание...               │
│ Код: X7K2PQ  │ Код: AB12CD               │
└──────────────┴───────────────────────────┘
```

### Создать команду
1. Нажми **Создать команду** (синяя кнопка справа)
2. В модальном окне введи **Название** (обязательно) и **Описание**
3. Нажми **Создать** → откроется страница новой команды

### Вступить в команду по коду
1. Нажми **Вступить** (серая кнопка)
2. Введи **код приглашения** (6 символов, виден на карточке команды)
3. Нажми **Вступить** → команда появится на дашборде

---

## Страница команды

**URL:** `http://localhost:8000/web/teams/{id}`

Три вкладки: **Задачи**, **Участники**, **Встречи**.  
В правом углу — кнопка **Календарь** и отображение кода приглашения.

---

### Вкладка «Задачи»

```
┌─────────────────────┐  ┌────────────────────────┐
│ Список задач  [+]   │  │ Написать API            │
│                     │  │ Статус: В работе  ▼     │
│ [Открыта] Задача 1  │  │ [Изменить]              │
│ [В работе] Задача 2 │  │────────────────────────│
│ [Готово]   Задача 3 │  │ Комментарии            │
│                     │  │ user: Взял в работу    │
│                     │  │ [Написать комментарий ] │
└─────────────────────┘  └────────────────────────┘
```

**Создать задачу:**
1. Нажми **+ Новая задача**
2. Заполни **Название** (обязательно), описание, дедлайн, исполнителя
3. Нажми **Создать**

**Посмотреть детали и комментарии:**
1. Кликни по любой задаче в списке
2. Справа откроется панель с деталями, статусом и комментариями

**Изменить статус задачи:**
1. В правой панели выбери новый статус из дропдауна
2. Нажми **Изменить** → статус обновится, бейдж изменит цвет

| Статус | Цвет бейджа |
|---|---|
| Открыта | Серый |
| В работе | Оранжевый |
| Готово | Зелёный |

**Написать комментарий:**
1. В правой панели введи текст в поле внизу
2. Нажми кнопку отправки (иконка самолётика)
3. Комментарий появится в списке выше

---

### Вкладка «Участники»

Отображает всех участников команды:
- Иконка пользователя + ID
- Дата вступления
- Роль: **Менеджер** (жёлтый бейдж) / **Участник** (серый бейдж)

---

### Вкладка «Встречи»

**Создать встречу:**
1. Нажми **+ Запланировать встречу**
2. Введи **Название**, **Дату и время начала**, **Дату и время конца**
3. Нажми **Создать**

> Если встреча пересекается по времени с существующей — отобразится ошибка.

Каждая встреча показывает:
- Название
- Время начала и конца
- Статус: **Активна** (зелёный) / **Отменена** (красный)

## Календарь команды

**URL:** `http://localhost:8000/web/teams/{id}/calendar`

Агрегированный вид всех задач с дедлайном и встреч за выбранный период.

```
┌─────────────────────────────────────────────┐
│  С [2026-05-01]  По [2026-05-31]  [Применить]│
├──────────────────────┬──────────────────────┤
│ • Задачи с дедлайном │ • Встречи            │
│                      │                      │
│ [Открыта] Задача 1   │ Еженедельный синк    │
│ 21.05.2026 18:00     │ 21.05.2026 10:00     │
│                      │             — 11:00  │
└──────────────────────┴──────────────────────┘
```

**Изменить период:**
1. Выбери даты в полях **С** и **По**
2. Нажми **Применить** → список обновится

**Перейти к задаче:**  
Клик по задаче в колонке "Задачи" → переходит на страницу команды с открытой панелью этой задачи.

## Навигация

| Откуда | Куда | Как |
|---|---|---|
| Любая страница | Дашборд | Логотип **TeamFlow** в навбаре |
| Дашборд | Страница команды | Клик по карточке команды |
| Страница команды | Дашборд | Кнопка ← (стрелка назад) |
| Страница команды | Календарь | Кнопка **Календарь** справа |
| Календарь | Страница команды | Кнопка ← (стрелка назад) |
| Задача в календаре | Задача в команде | Клик по задаче |

---

## Сообщения об ошибках и успехе

Все уведомления отображаются в виде алертов под навбаром:
- 🔴 **Красный алерт** — ошибка (неверные данные, нет доступа, конфликт)
- 🟢 **Зелёный алерт** — успешное действие (задача создана, вступил в команду)

Алерты автоматически закрываются кнопкой ✕ или при следующей навигации.
